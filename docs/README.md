# Документация проекта «Вместе»

Этот каталог — основной источник продуктовой, архитектурной и инженерной документации проекта. Документы хранятся рядом с кодом и изменяются вместе с репозиторием.

## Навигация

| Раздел | Назначение | Статус |
| --- | --- | --- |
| [Product Requirements Document](product/prd.md) | Цели продукта, пользователи, scope MVP и требования | Draft, версия 0.1 |
| [Открытые продуктовые вопросы](product/open-questions.md) | Нерешённые вопросы и уже зафиксированные решения | Draft |
| [Architecture](architecture/README.md) | Будущие архитектурные документы | Подготовлен раздел |
| [ADR](adr/README.md) | Журнал отдельных архитектурных решений | Приняты первые 6 решений |
| [AI](ai/README.md) | Будущие правила AI-assisted разработки | Подготовлен раздел |

## Правила

- Markdown в `docs/` является источником истины для разработки.
- Существенные изменения требований обновляют PRD или ссылаются на него.
- Нерешённые продуктовые вопросы ведутся в `product/open-questions.md`.
- Самостоятельные архитектурные решения фиксируются в ADR.
- Планируемые документы не считаются принятыми решениями, пока не созданы и не обсуждены.
- Внутренние ссылки оформляются относительными путями.

System Design пока не создан: этот этап оставлен до отдельного обсуждения.
