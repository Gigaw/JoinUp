# AI-assisted development

Раздел зарезервирован для будущей документации по использованию AI в разработке:

- рабочий процесс от требования до реализации и review;
- правила выбора контекста для агентов;
- границы ответственности разработчика и агента;
- проверка сгенерированного кода;
- полезные инструменты и интеграции;
- передача контекста между задачами.

Конкретные процессы и обязательные инструменты пока не зафиксированы.
