# Architecture

Раздел содержит принятую и проектируемую техническую архитектуру проекта «Вместе». Продуктовое
поведение остаётся в [`../product/prd.md`](../product/prd.md), а отдельные решения и альтернативы —
в [`../adr/`](../adr/README.md).

## Правила изменений

- Изменение продукта сначала отражается в PRD, затем в зависимых архитектурных документах.
- Решение с долгосрочными последствиями оформляется отдельным ADR.
- Публичные API не возвращают точную дату рождения, password data или session data.
- Изменение модели участия проверяется относительно всех продуктовых инвариантов и concurrency
  scenarios.
- Планируемая точка расширения не означает, что отложенный модуль входит в текущий каркас.
