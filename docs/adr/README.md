# Architecture Decision Records

Здесь будут храниться отдельные архитектурные решения (ADR) с контекстом, вариантами и последствиями.

Формат имени:

```text
NNNN-short-decision-title.md
```

Каждая запись должна содержать статус, дату, контекст, варианты, решение, последствия и ссылки на связанные требования.

ADR пока не созданы: архитектурные решения ещё обсуждаются.
