# Architecture Decision Records

В этом каталоге хранятся решения, которые ограничивают дальнейшую реализацию проекта «Вместе».
Продуктовое поведение остаётся в PRD, а подробное устройство системы — в документах
[`../architecture/`](../architecture/README.md).

## Жизненный цикл

ADR создаётся со статусом `Предложено`. После обсуждения статус меняется на `Принято` или
`Отклонено`. Принятое решение не переписывается при существенном изменении архитектуры: вместо
этого создаётся новый ADR со статусом `Принято`, а прежний получает статус `Заменено` и ссылку на
новое решение.

Допустимые статусы:

- `Предложено` — решение обсуждается и ещё не ограничивает реализацию;
- `Принято` — решение обязательно для новых изменений;
- `Отклонено` — вариант рассмотрен, но не выбран;
- `Заменено` — действует более новый ADR.

Исправления опечаток, ссылок и формулировок без изменения смысла можно вносить в существующий
ADR. Изменение самого решения требует нового документа.

## Нумерация и формат

Имя файла имеет вид `NNNN-short-decision-title.md`. Номер назначается последовательно и не
переиспользуется после отклонения или замены решения. Название файла и технические идентификаторы
пишутся на английском, текст документа — на русском.

Для нового решения нужно:

1. скопировать [`template.md`](template.md);
2. назначить следующий свободный номер;
3. описать контекст, варианты и последствия;
4. добавить документ в журнал ниже;
5. связать ADR с требованиями и GitHub Issues;
6. обновить зависимые архитектурные документы в той же задаче.
